จุดที่ต้องระวัง

Database strategy

database.module.ts ใช้ synchronize: true แต่ data-source.ts ใช้ migrations และ synchronize: false อย่าสลับ strategy โดยไม่ดู environment

API path mismatch

Backend auth อยู่ใต้ /auth/* แต่ Flutter constants บางตัวใช้ /register//logout ตรง root และบาง resource ต่อ slash ซ้ำ

Localhost

Flutter ตั้ง base URL เป็น http://localhost:3001/api/v1/; Android emulator/device อาจต้องเปลี่ยน host และตั้ง network permission
